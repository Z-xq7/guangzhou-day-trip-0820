# 广州情侣一日游互动路线

2026 年 8 月 20 日从深圳出发的广州一日游互动网页，同时提供 30 个广州精选地点的发现指南。

- 21 个景点、9 家粤味，支持搜索、行政区、受众、主题、预算与排序筛选。
- 30 张本地 WebP 实景/食物示意照片，逐项附原图、许可和修改说明。
- 透明的站内推荐分、停留时间、预算、适合人群、开放提示与核验来源。
- 本地静态广州总览图、编号点位、密集点选择器及百度地图精确地点链接。
- 手机端“路线 / 发现 / 地图 / 待办 / 我的”五功能导航，支持深链接与浏览器前进后退。
- 想去清单、打卡、模式与待办仅保存在当前设备，不请求定位、不上传数据。

公开访问：<https://z-xq7.github.io/guangzhou-day-trip-0820/>

## 本地开发

要求 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

## 验证与构建

```bash
npm run lint
npm test
npm run build:pages
```

- `npm run build`：现有 Vinext/Sites 构建。
- `npm run build:pages`：输出 GitHub Pages 静态文件到 `dist-pages/`。
- 路线与发现地图均使用本地静态资源，不加载地图网络资源；仅当用户点击导航链接时，才会打开百度地图。
- 地点资料最后核验日期为 2026-08-12；出行前仍应通过卡片内官方来源复核临时闭馆、票价与预约要求。
